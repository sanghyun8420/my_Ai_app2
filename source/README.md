# 수박정원 · 개발 소스

[GitHub Pages 게임](https://sanghyun8420.github.io/my_Ai_app2/) · [기존 사이트/API](https://suika-shake-garden-n5k7.hbhbhs02.chatgpt.site)

수박정원, 사과모아, 블록정원, 과일 원정대, 사과 키우기를 하나의 사이트에서 고르는 한국어 게임입니다. 새 과학 모드는 수박정원의 모드 화면에서 엽니다.

다른 AI에게 이어서 개발을 맡길 때는 먼저 [HANDOFF.ko.md](./HANDOFF.ko.md)를 전달하세요. GitHub 저장소의 공개 실행 파일은 루트에, 이 개발 프로젝트는 `source/`에 들어 있습니다. 전체 소스 ZIP을 풀었다면 이 문서가 있는 곳이 프로젝트 루트입니다.

## 시작

Node.js 24 LTS를 권장합니다. 최소 버전은 22.13이며, API 테스트에서 `node:sqlite`를 사용합니다.

```sh
npm install
npm test
npm run build
npm run dev
```

`npm run dev`는 기본 `http://localhost:4173`에서 게임과 로컬 SQLite API를 함께 실행합니다. 로컬 계정·친구 데이터는 `.local/`에 저장되며 실제 공개 사이트 데이터와 분리됩니다. 포트는 `PORT` 환경변수로 지정할 수 있습니다.

`npm install`은 그림 검사용 `@napi-rs/canvas` 개발 의존성을 설치합니다. 설치 없이 실행 가능한 검사만 하려면 `npm run test:core`를 사용합니다. 게임 본체는 외부 프레임워크 없이 HTML/CSS/JavaScript로 실행됩니다.

GitHub 저장소에서 소스를 수정한 뒤 공개 파일을 갱신하려면 저장소 루트에서 실행합니다.

```sh
node source/scripts/sync-pages.mjs
```

이후 변경 파일을 검토·커밋하고 `main`에 올리면 현재 GitHub Pages의 브랜치 배포가 실행됩니다. 기존 Sites API 서버의 변경은 별도 Sites 배포가 필요합니다.

## 파일

- `dist/`: 게임 화면과 브라우저 로직. 개발할 때 수정하는 원본입니다.
- `worker/`: 계정·친구·메시지·대전·리더보드 API.
- `drizzle/`: D1 데이터베이스 마이그레이션.
- `tests/`: 게임 규칙·경제·저장·모드·API 회귀 검사.
- `scripts/`: Worker 빌드, Pages 내보내기·동기화, 그림 검사.
- `.openai/hosting.json`: 기존 Sites의 식별자와 DB 바인딩. 인증 정보는 들어 있지 않습니다.
- `HANDOFF.ko.md`: 기능, 저장 구조, 검증 범위, 배포 관계를 설명합니다.

## 현재 규칙

- 동전은 게임별로 사용하고 보석은 다섯 게임이 공유합니다. 도구·뽑기·강화·부활·씨앗은 해당 게임 동전, 스킨·배경·꾸미기는 공용 보석으로 삽니다.
- 예전 다섯 보석 잔액과 미처리 환급을 한 번만 합산합니다. 기존 소유권을 유지하며 구매·보상과 진행 기록을 한 번의 저장으로 기록합니다.
- 사과모아는 나가거나 재접속하면 새 판입니다. 기본 수박·블록·성장 게임의 저장은 유지하며, 수박 특수 모드는 나가거나 재접속하면 기본 수박게임으로 돌아옵니다.
- 과학 모드는 수소 두 개와 산소 하나를 정확히 소비해 물을 만듭니다. 물 이후의 구름·성운·별·초신성은 게임용 테마 성장입니다.
- 회원가입 없이 닉네임을 정하면 기존 기기의 최고점수도 공통 리더보드에 등록합니다. 같은 이름은 같은 사람으로 취급하지 않고 비공개 복구 코드로 구별합니다.
- 기기 자동 저장에 더해 닉네임으로 참여한 진행을 약20초마다 서버에 백업합니다. 다른 주소·기기에서는 ‘내 이름과 기록’의 복구 코드를 입력하고 서버 기록을 불러옵니다. 더 새로운 서버 기록이 있으면 선택하기 전까지 덮어쓰지 않습니다.
- 기존 로그인·친구·대전 API도 유지합니다. 지갑과 점수는 플레이어 기기에서 계산하며 서버 권위 결제나 부정행위 방지 시스템은 아닙니다.

실제 모바일·태블릿 브라우저의 최종 화면·음성은 이 개발 환경에서 직접 검증하지 못했습니다. 규칙·경제·저장·Canvas·SQLite 검사는 제공된 테스트로 확인할 수 있습니다.

## 홈 화면에 추가

35초 플레이 후 뜨는 안내 또는 메뉴의 ‘홈 화면에 추가’를 사용합니다. 지원 브라우저는 실제 설치 창을 열고, 아이폰은 Safari 공유→홈 화면에 추가 절차를 안내합니다. 닫으면7일 동안 자동 안내를 쉬며, 이미 설치한 경우에는 자동으로 띄우지 않습니다.

로그인이나 설치를 하지 않아도 최고 기록·보석·스킨은 같은 기기·브라우저·사이트 주소에 자동 저장합니다. 브라우저 데이터를 삭제하거나 다른 브라우저·주소로 이동하면 별도 기록이므로 서버 복구 코드를 사용합니다. 설치 후 오프라인에는 혼자 플레이할 수 있으며 친구·순위·서버 저장은 인터넷 연결이 필요합니다.

## 계정과 보석

처음에는 로그인 없이 바로 플레이합니다. 상단 로그인 팝업 하단의 회원가입 또는 설정의 ‘회원가입하면 보석500개’를 사용합니다. 새 아이디는 영문·숫자를 모두 넣어4~20자, 비밀번호는 영문·숫자를 포함하는8~128자(대소문자 구분)이며 확인 입력이 필요합니다. 중복 아이디는 등록할 수 없습니다. 게스트 기록을 보존해 계정으로 전환하고 가입 보상을 한 번 지급합니다.

기본 보석은 수박20과일·사과20칸·블록16칸·원정대20처치·사과 키우기1수확마다5개입니다. 기존 잔액과 스킨은 유지하며 새 진행부터 적용합니다. Google·Apple 앱 등록 정보는 아직 설정되지 않았습니다.

특별 배는 금빛으로 반짝입니다. 합치거나 도구로 정리한 특별 배3개마다 보석1~5개를 무작위로 받고, 남은1~2개는 다음 판에도 이어집니다. 게임판 위의 ‘🍐0/3’에서 확인할 수 있습니다. 새로고침해도 이미 받은 보상을 다시 주지 않습니다.
