# 수박정원 · 게임방 업데이트

## 특별 배를 모으면 보석이 톡!

- 금빛으로 반짝이는 특별 배를 추가했습니다. 특별 배3개를 합치거나 정리할 때마다 보석1~5개를 무작위로 받습니다. 특별 배 두 개가 서로 합쳐지면2개로 셉니다.
- 지우개·3개 정리·부활 정리·최종 폭발에도 적용합니다. 현재 모은 개수를 게임판 위에 작게 표시하며 남은1~2개는 다음 판에 이어집니다.
- 저장·새로고침·서버 복구 후에도 같은 배로 보상을 다시 받지 않도록 했습니다. 특별 사과의 도구 보상과 기본 보석 획득은 유지합니다.

## 바로 플레이 · 선택형 회원가입과 더 쉬운 보석 모으기

- 처음에는 게스트로 바로 플레이하며 상단에 로그인 버튼을 둡니다. 로그인 팝업 아래 ‘계정이 없으신가요? 회원가입’으로 가입하고, 설정에서도 ‘회원가입하면 보석500개’ 안내를 엽니다.
- 닉네임, 영문·숫자 조합 아이디, 비밀번호, 비밀번호 확인을 입력합니다. 아이디 중복은 실제 서버에서 확인하고 등록을 막습니다. 비밀번호는 영문·숫자를 포함하는8~128자이며 대소문자를 구분합니다.
- 가입 보상500개를 서버에 한 번 기록합니다. 게스트의 기존 기록·보석·스킨·친구 코드를 유지하고, 다른 기기의 저장과 충돌하면 가입과 보상을 함께 되돌려 안전하게 다시 시도합니다.
- 보석을 수박20과일·사과20칸·블록16칸·원정대20처치·사과 키우기1수확마다5개씩 줍니다. 기존 지갑은 그대로 두고 새 진행부터 적용합니다.
- 쫄라맨을 누르면 말풍선만 나오며 몸이나 다리는 움직이지 않습니다.
- Google·Apple은 앱 등록 정보가 없어 이번 업데이트에서는 연결하지 않았습니다.

## 홈 화면에서 바로 여는 수박정원

- 게임을35초 플레이하면 ‘홈 화면에 바로가기 추가하기’를 안내합니다. 다른 창과 겹치지 않고, 닫으면7일 동안 다시 자동으로 표시하지 않습니다. 메뉴에서도 다시 열 수 있습니다.
- 지원하는 브라우저에서는 실제 앱 설치 창을 연결하고, 아이폰은 Safari의 공유→홈 화면에 추가 방법을 안내합니다. 수박 아이콘과 앱 화면을 추가했습니다.
- 설치 여부나 로그인과 관계없이 최고 기록·지갑·스킨은 기존 브라우저에 자동 저장합니다. 설치 시작 주소도 기존 게임 주소를 유지합니다.
- 설치 후 오프라인으로 혼자 플레이할 수 있도록 정적 게임 파일을 준비합니다. API 응답·인증 정보·다운로드 ZIP은 캐시하지 않으며, 업데이트 때문에 진행 중인 게임을 강제로 다시 열지 않습니다.

## 이름만 정하고 시작 · 공통 순위와 서버 백업

- 첫 방문에는 회원가입 대신 이름 입력 칸이 열립니다. 기존 브라우저에 남은 수박·사과·블록의 최고점수도 해당 이름으로 리더보드에 올립니다. 예전 계정 로그인도 선택해서 사용할 수 있습니다.
- GitHub Pages와 기존 사이트는 같은 순위 서버를 봅니다. 동일한 닉네임을 쓰는 사람이 있어도 기록이 섞이지 않습니다.
- 기기 자동 저장을 유지하면서 진행·보석·동전·보유 스킨·설정을 서버에 백업합니다. 메뉴의 ‘내 이름과 기록’에서 저장 상태와 복구 코드를 확인합니다.
- 다른 주소나 기기에서는 기존 기기의 복구 코드를 한 번 입력해 이어갑니다. 더 최신 서버 기록이 있으면 선택하기 전까지 덮어쓰지 않고, 불러오기 전에 이 기기의 기존 기록도 백업합니다. 이름만으로 다른 사람의 저장 기록을 가져올 수는 없습니다.
- 저장·복구 실패나 네트워크 끊김이 기기의 기존 기록을 지우지 않도록 했습니다. 기존 보석을 복원할 때 이전 잔액을 다시 합산하지 않습니다.

## 과학 정원과 전체 소스 인수인계

- 모드 창에서 ‘과학 정원’을 바로 선택합니다. 수소2개+산소1개를 실제로 소비해 물을 만듭니다. H+H→H₂, H₂+O→H₂O 또는 H+O→OH, OH+H→H₂O 순서가 모두 가능합니다. 산소끼리 만나 수소로 바뀌는 식의 잘못된 합성은 하지 않습니다.
- 물 이후는 게임용 우주 테마 성장입니다. 물방울→구름→성운→원시별→무거운 별→적색초거성→철핵→핵붕괴→초신성으로 진행합니다. 마지막에는 섬광·충격파와 함께 주변 물질을 정리하고 점수 이미지를 공유합니다.
- 원자와 분자 그림, 별 단계, 다음 원자와 반응식을 표시합니다. 재료는 수소2:산소1 비율로 공급하며 특별사과는 등장하지 않습니다. 과학 점수는 별도로 저장하고 과일 발견·기본 게임 업적은 해제하지 않습니다.
- 친구 대전·저장 형식도 과학 모드를 인식합니다. 다른 특수 모드와 마찬가지로 나가기·재접속 후에는 기본 수박게임으로 돌아갑니다.
- GitHub 저장소에 편집 원본 `source/`, 전체 소스 `source-code.zip`, 개발·배포 안내와 다른 AI에게 전달할 `CONTINUE.ko.md`를 함께 제공합니다. 원본을 수정한 뒤 동기화 스크립트로 공개 파일을 갱신합니다.

## 게임별 동전 · 다섯 게임 공용 보석

- 수박·사과모아·블록정원·원정대·사과 키우기에서 각각 동전을 벌고, 해당 게임의 도구·부활·장비 뽑기·강화·씨앗에 사용합니다. 동전은 게임 사이에 섞이지 않습니다.
- 보석은 다섯 게임이 함께 쓰며 스킨·배경·바구니·쫄라맨 꾸미기에 사용합니다. 성장 게임과 퍼즐의 꾸미기 화면에서도 공용 보석으로 수박정원 상점을 열 수 있습니다.
- 기존 다섯 보석 잔액과 삭제된 도구·공룡 스킨의 미처리 환급을 한 번만 합산합니다. 보유 스킨·장비·업적·기존 동전은 유지하며, 예전 개별 저장값은 백업으로 보존합니다. 이후 구매·보상·진행 기록과 공용 보석을 하나의 저장으로 기록합니다.
- 수박은 정리한 과일마다 동전1개, 사과·블록은 정리한 칸마다 동전1개를 줍니다. 원정대 처치 동전과 정원 수확 동전은 유지합니다. 원정대 뽑기는 동전60/600개, 정원의 장미·별빛 씨앗은 동전600/1,400개입니다.
- 업적과 원정대 첫 보스 처치로 공용 보석을 받습니다. 추가로 수박200과일·사과100칸·블록80칸·원정대100처치·정원5수확마다 보석1개를 지급합니다. 이전 진행량과 같은 보상을 다시 세지 않습니다.
- 광산 스킨의 합치기 보너스는 수박 동전1/10개로 바뀌며 기존 소유권을 유지합니다. 새 원정대나 정원을 열 때 보석이 반복 지급되지 않습니다.
- 저장 실패 시 구매·뽑기·업적 결제를 복구하고, 오래된 다른 창이 같은 게임 보상을 중복 기록하지 못하도록 확인합니다. 기기·브라우저·사이트 주소 사이에서는 위의 서버 백업·복구 코드 방식을 사용합니다.

## 아이템 추가와 오류 수정 · 게임 나가기

- 원정대의 길과 길 위의 돌을 없애고 잔디 숲으로 통일했습니다. 전진 시 적의 표시 위치와 타격 효과를 맞추고, 앞에 도착하지 않은 적이 멈춰 서 보이던 문제와 이전 전투의 잔여 이동을 수정했습니다.
- 도구를 9종에서 21종으로 늘렸습니다. 씨앗 새총·새싹 방울·버섯 모자·완두콩 활·산딸기 반지·잎새 우산·서리 낫·반딧불 랜턴·비구름 수정·혜성 대검·정원 왕관·불사조 깃털은 각기 다른 그림과 공격·체력·회복 조합을 갖습니다. 희귀도 확률·확정 횟수는 유지하며 뽑기 재화는 동전으로 바뀌었습니다.
- 장비를 옮긴 뒤 재접속하면 원래 동료에게 돌아가던 문제, 중복 강화 수치가 카드에 반영되지 않던 문제를 수정했습니다.
- 터치로 처치한 적이 다시 공격하던 문제, 제한시간 직전에 처치한 보스가 실패로 처리되던 문제, 보스전에서 다시 시작이 동작하지 않던 문제를 수정했습니다. 보상은 한 번만 지급합니다.
- 두 성장 게임 중 하나만 저장에 실패해도 성공으로 표시되던 문제를 수정했습니다.
- 사과모아는 다른 게임으로 나가거나 재접속하면 새 판으로 시작합니다. 보석·스킨·최고 기록은 유지합니다. 블록정원은 기존처럼 진행 중인 판을 이어갑니다.
- 수박 특수 모드는 나갔다 돌아오거나 사이트에 다시 접속하면 기본 수박게임으로 돌아갑니다. 기본 수박게임의 자동 이어하기는 유지하고, 모드 기록은 모드별 최고점수에 남습니다. 메뉴를 잠깐 열었다 닫는 것은 게임 나가기로 처리하지 않습니다.

## 처치할 때마다 앞으로 나아가는 원정대

- 썩은 과일을 처치할 때마다 원정대가 걷고 화면이 부드럽게 옆으로 이동합니다. 연속 처치한 이동량도 이어서 반영합니다.
- 먼 산·나무·풀을 서로 다른 속도로 흘려보내고, 걷는 발과 망토·먼지 움직임을 연결했습니다. 살아 있는 적과 타격 효과도 화면 이동을 함께 따라갑니다.
- 보스전과 쉬는 중에는 전진을 멈추고, 보스 승리 후에는 더 멀리 이동합니다. 메뉴·게임 선택·다른 게임을 보는 동안에는 이동이 진행되지 않습니다.
- 기기의 ‘동작 줄이기’ 설정에서는 화면 이동을 생략합니다. 전투 좌표·난이도·보상·저장 기록은 변경하지 않습니다.

## 더 크고 생기 있는 과일 원정대

- 모바일 전투 화면의 32dvh 제한을 없애 가로 폭을 모두 사용하고, 태블릿·PC에서도 전투 화면에 더 넓은 자리를 배정했습니다. 동료와 적도 확대했습니다.
- 동료별 돌진·무기 휘두르기·마법탄·화살 동작, 망토와 발 움직임, 눈 깜빡임을 추가했습니다.
- 적이 통통 뛰며 접근하고 맞으면 움찔합니다. 처치 시 회전하며 사라지는 동작과 동전·타격 파편, 보스 등장·분노·승리 효과를 추가했습니다.
- 숲의 색을 밝히고 구름·새·나비·풀·나뭇잎이 움직이도록 했습니다. 창을 열어 전투를 멈추면 연출도 함께 멈추며, 기기의 ‘동작 줄이기’ 설정에서는 배경 움직임과 화면 흔들림을 줄입니다.
- 강화·보스 난이도·보상·기존 저장 기록은 유지됩니다.

## 과일 원정대와 사과 키우기

- 제목을 누르면 다섯 게임을 선택합니다. 새 게임별 동전·성장 기록과 공용 보석을 자동 저장합니다.
- 과일 원정대는 모아(사과 기사), 포리(배 마법사), 루미(이슬 궁수)가 썩은 과일과 싸우는 자동 전투입니다. 화면을 터치해 추가 공격하고, 처치 동전으로 무기 공격력·최대 체력·회복을 강화합니다.
- 쉬움·보통·어려움·매우 어려움·지옥에 각각 1-1~3-5가 있습니다. 썩은 과일 10마리를 처치하면 35초 보스전에 도전합니다. 실패해도 동전·강화·장비를 유지하고 재도전합니다. 3-5 보스를 처치하면 다음 난이도가 열립니다.
- 원정 동전60개로 도구 1회, 600개로 10회 뽑습니다. 일반60%·희귀28%·영웅10%·전설2%, 영웅 이상은 최대30회 안에 확정입니다. 중복 도구는 자동 강화되고, 도구21종을 동료별 무기·호신구에 장착합니다.
- 사과 키우기는 물·영양·햇살·벌레 잡기를 통해 씨앗→새싹→나무→꽃→열매→수확으로 진행합니다. 수확 동전으로 정원을 강화하고, 홍옥·초록사과·황금사과·장미사과·별빛사과를 구합니다.
- 사과는 다른 게임을 하거나 재접속할 때 최대8시간의 성장 시간을 반영합니다. 물이 없으면 성장이 멈추고, 익은 사과는 직접 수확하므로 자리를 비운 동안 보석을 반복 생산하지 않습니다.
- 새 성장 게임은 혼자 즐기는 게임이며 기기별 성장 목표와 보상을 제공합니다. 친구 대전과 계정 리더보드는 수박·사과모아·블록정원에서 사용합니다.

## 스킨 그림과 상점 표시

- 상점 아이콘 옆에 ‘상점’을 표시합니다. 친구 버튼과 함께 작은 화면에서도 글자가 잘리지 않도록 간격을 조절했습니다.
- 자동차 14단계는 브랜드 엠블럼의 형태와 금속 질감을 다시 그렸고, 행성 14단계는 수성·금성·지구·화성·목성·토성·천왕성·해왕성 등 실제 천체의 특징을 담았습니다.
- ‘3D 과일’ 스킨(보석 80개)을 추가했습니다. 체리부터 태양의 열매까지 각기 다른 모양과 명암·반사광·껍질 질감을 사용합니다. 복잡한 그림은 캐시해 플레이 중 다시 그리는 부하를 줄였습니다.
- 공룡 스킨은 모든 상점에서 제거했습니다. 수박게임의 기존 구매분은 같은 가격의 3D 과일로 교체하고, 사과모아·블록정원의 기존 구매분은 각 게임 보석 60개로 한 번만 돌려줍니다.

## 게임 선택과 퍼즐 조작 개선

- 수박정원의 바구니 크기를 실제 보이는 화면 높이에 맞춥니다. 세로 화면의 도구는 아래에, 넓은 화면의 도구는 옆에 배치하여 제목·상점 버튼·바구니·도구를 함께 보여줍니다.
- 쫄라맨은 ‘지금 점수’ 칸 위에 앉습니다. 주소창·화면 회전·도구 안내 높이가 변하면 배치를 다시 계산합니다.
- 상단 수박정원 제목을 한 번 누르면 게임 선택 카드 세 장이 열립니다. 제목 아래 작은 화살표와 안내를 넣었습니다.
- 상점·모드·친구 버튼을 상단 오른쪽에 같은 크기로 모았습니다. 휴대폰에서도 친구 버튼을 바로 사용할 수 있고, 배경색 설정은 메뉴 안에서 엽니다.
- 사과모아의 사과와 숫자를 키우고 입체적인 사과 그림, 선택 영역의 합계, 수확 연출을 더했습니다. 좁은 세로 화면에서도 큰 판을 볼 수 있게 조정했습니다.
- 블록정원은 끄는 블록이 손가락·마우스를 따라 움직이며, 판 위에 놓일 자리를 미리 보여줍니다. 블록과 게임판의 질감, 줄 정리와 연속 정리 연출을 다듬었습니다.
- 게임 선택 중에는 진행을 멈추며, 수박정원으로 돌아오면 이전 판을 이어갑니다. 동전과 기록은 게임별로, 보석은 공용으로 유지됩니다.

## 플레이

- 수박정원, 가로 화면의 사과모아, 세로 구성의 블록정원을 사이트 안에서 전환합니다.
- 사과모아는 네모 영역 안 숫자의 합을 10으로 만드는 120초 퍼즐입니다. 블록정원은 8×8 판의 가로·세로 줄을 채우는 퍼즐입니다. 이름과 그림은 자체 제작했습니다.
- 게임별 동전·스킨·기록·업적을 보존하고 보석 잔액은 공유합니다. 기본·시간 도전·챌린지 기록을 나눕니다.
