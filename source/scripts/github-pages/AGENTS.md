# 수박정원 저장소 작업 안내

이 저장소는 이미 공개 중인 수박정원 게임입니다. 현재 상태에서 이어서 개발합니다.

- 먼저 `source/HANDOFF.ko.md`와 `CONTINUE.ko.md`를 읽습니다.
- 수정 원본은 `source/`입니다. 루트의 실행용 HTML/JS만 따로 고치지 않습니다.
- 브라우저 소스는 `source/dist/`, API는 `source/worker/`, 데이터베이스 마이그레이션은 `source/drizzle/`입니다.
- Node.js 24 LTS 권장(최소22.13). `source/`에서 `npm install`, `npm test`, `npm run build`를 실행합니다. `npm run dev`는 localhost:4173의 로컬 게임/API를 실행하고 `.local/`에 별도 SQLite를 만듭니다.
- 저장소 루트에서 `node source/scripts/sync-pages.mjs`로 공개 파일을 갱신하고 생성된 변경도 함께 검토·커밋합니다.
- GitHub Pages는 `main`의 `/(root)`를 배포합니다. 기존 Sites API 배포는 별도 권한/도구가 필요합니다. GitHub 푸시만으로 서버 코드가 바뀌었다고 안내하지 않습니다.
- 현재 API 주소와 Sites 식별자를 임의로 바꾸거나 새 사이트를 만들지 않습니다.
- `garden-economy-v1`과 레거시 이전 영수증·소유권·게임 기록을 보존합니다. 개별 보석 잔액을 다시 합산하거나 데이터 초기화로 오류를 숨기지 않습니다.
- 사과모아는 나가면 새 판, 블록과 기본 수박은 이어하기, 수박 특수 모드는 나가기/재접속 후 기본 게임 복귀를 유지합니다.
- 과학 모드의 원자 반응은 실제로2H+O를 소비해야 합니다. 물 이후는 게임 테마 성장임을 구분합니다.
- 닉네임 플레이의 복구 키는 비밀 인증 수단입니다. 이름만으로 소유권을 복원하지 않고 서버 백업의 버전 충돌·복원 전 기기 백업·페이지 초기화 전 적용을 유지합니다.
- 비밀번호·토큰·인증 쿠키·개인 DB를 코드나 응답에 넣지 않습니다. 연결된 도구의 정상 인증 방식을 사용합니다.
- 검증한 내용과 실제 브라우저/기기에서 확인하지 못한 내용을 구분해 알립니다.
