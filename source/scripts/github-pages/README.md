# 🍉 수박정원 · 다섯 가지 작은 게임

**[수박정원 플레이](https://sanghyun8420.github.io/my_Ai_app2/)**

제목을 누르면 수박정원·사과모아·블록정원·과일 원정대·사과 키우기를 고를 수 있습니다. 동전과 성장 기록은 게임별로 유지하고, 보석은 다섯 게임이 함께 사용합니다.

- 수박정원: 과일 합치기, 보호되는 흔들기, 선택 지우개, 다양한 스킨과 모드
- 사과모아: 네모 안 사과 숫자의 합을10으로 만드는 가로 퍼즐
- 블록정원: 블록을 끌어 가로·세로 줄을 채우는 퍼즐
- 과일 원정대: 세 동료의 자동 전투, 동전 강화·장비 뽑기, 쉬움부터 지옥까지75보스 구간, 21종 도구 뽑기와 장착
- 사과 키우기: 물·영양·햇살, 수확과 정원 강화, 다섯 품종, 자리를 비운 동안의 성장

사과모아는 나가면 새 판으로 시작하며, 수박 특수 모드는 나가거나 재접속하면 기본 수박게임으로 돌아갑니다. 보석·스킨·최고점수는 유지됩니다.

게임별 음악·효과음 설정, 자동 저장, 이름만 입력하는 플레이와 선택형 기존 계정 로그인, 수박·사과·블록 친구 대전 및 리더보드를 제공합니다. 원정대와 사과 키우기는 개인 성장 게임입니다.

도구·장비·부활·씨앗은 해당 게임 동전으로, 스킨·배경·꾸미기는 공용 보석으로 구매합니다. 기존 보석과 환급은 한 번만 합산하고 구매 내역은 유지합니다. 업적·첫 보스·누적 플레이 보상으로 공용 보석을 얻습니다.

## 다른 AI와 개발 이어가기

[전체 개발 코드 ZIP](./source-code.zip) · [개발 인수인계](./source/HANDOFF.ko.md) · [다른 AI에게 전달할 문장](./CONTINUE.ko.md)

이 저장소의 루트 HTML/JS는 GitHub Pages 실행 파일이고, 수정 원본은 `source/`에 있습니다. GitHub가 연결된 다른 AI에게 위 인수인계와 전달 문장을 읽게 하면 현재 코드에서 이어갈 수 있습니다. 비밀번호·토큰은 코드에 포함하지 않습니다.

Node.js24 LTS 권장(최소22.13)입니다. 저장소를 체크아웃한 뒤:

```sh
cd source
npm install
npm test
npm run build
npm run dev
# 로컬 확인 후 서버를 종료하고 다음 명령을 실행합니다.
cd ..
node source/scripts/sync-pages.mjs
```

`npm run dev`는 `http://localhost:4173`에서 게임과 별도 로컬 SQLite API를 실행합니다. 실제 서비스의 계정 DB를 복사하거나 변경하지 않습니다.

검사와 동기화 후 변경 파일을 커밋·푸시합니다. Pages 설정은 `main` 브랜치의 `/(root)`이며 main 변경 사항이 새 버전으로 배포됩니다. 독립 소스 ZIP에서 작업한다면 `node scripts/sync-pages.mjs /absolute/pages-root`로 별도 공개 폴더를 지정합니다.

GitHub 연결은 기존 Sites API의 배포 권한까지 복사하지 않습니다. 프론트엔드 수정은 현재 API 주소를 유지해 계속 진행할 수 있고, 서버 변경은 인수인계 문서의 별도 배포 절차를 확인해야 합니다.

닉네임·친구·리더보드·방·진행 백업은 기존 수박정원 Worker/D1 API를 사용합니다. 이름만 정하면 이 브라우저의 예전 최고점수도 등록합니다. 진행은 기기와 서버에 저장하며 다른 주소·기기에서는 ‘내 이름과 기록’에서 복구 코드를 입력해 불러옵니다. 닉네임이 같다는 이유로 다른 사람의 기록을 가져오지 않으며 더 새로운 서버 기록을 자동으로 덮어쓰지 않습니다. 장비 뽑기는 게임 안에서 얻는 원정 동전을 사용하며 현금 결제는 없습니다.
