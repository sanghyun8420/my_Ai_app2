# 🍉 수박정원

같은 과일을 합쳐 수박과 비밀 과일에 도전하는 무료 웹 게임입니다.

**게임 주소 (GitHub Pages 활성화 후): https://sanghyun8420.github.io/my_Ai_app2/**

휴대폰·태블릿·컴퓨터에서 플레이할 수 있습니다. 흔들기, 선택 지우개, 작은 과일 정리, 보석 상점과 스킨, 물·우주 등 비밀 모드, 업적과 자동 이어하기를 지원합니다. 회원가입·친구·초대·방 기능은 기존 수박정원 API를 사용합니다.

## 처음 공개할 때 한 번만 설정

1. [Settings → Pages](https://github.com/sanghyun8420/my_Ai_app2/settings/pages)를 엽니다.
2. Source를 **Deploy from a branch**로 고릅니다.
3. Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
4. GitHub의 배포가 끝나면 위 게임 주소로 접속합니다.

코드를 수정하여 main에 커밋하면 다시 배포됩니다.

## 검색 등록

Google Search Console에서 https://sanghyun8420.github.io/my_Ai_app2/ 를 URL 접두사 속성으로 추가하고 소유권을 확인한 뒤, sitemap.xml을 제출할 수 있습니다. 네이버는 서치어드바이저에서 사이트를 등록하고 소유 확인 후 수집을 요청할 수 있습니다. 수집 신청 없이도 검색로봇이 사이트를 발견할 수 있지만, 신청 여부와 무관하게 검색 노출·순위는 보장되지 않습니다.

## 데이터

기존 수박정원 계정으로 로그인할 수 있습니다. 계정 최고점수와 친구 목록은 기존 서버를 사용합니다. 로그인 세션은 탭 저장소에 보관되므로 탭을 닫은 후에는 다시 로그인해야 할 수 있습니다.

보석·구입 스킨·진행 중인 판은 기기와 사이트 주소별로 저장됩니다. 기존 주소의 기기 저장 내용이 새 주소로 자동 이전되지는 않습니다.

이 저장소에는 공개 게임 파일만 포함되어 있으며, 실제 회원 데이터나 서버 자격 증명은 포함되지 않습니다.
