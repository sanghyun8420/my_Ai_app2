## 실행과 수정

설치나 빌드 없이 GitHub Pages에서 실행합니다. Pages 설정은 main 브랜치의 /(root)를 사용합니다. main에 변경 사항을 커밋하면 새 버전이 배포됩니다.

계정·친구·리더보드·방 기능은 기존 수박정원 Worker/D1 API를 사용합니다. 로그인 세션은 자동 로그인 선택에 따라 로컬 저장소 또는 탭 저장소에 보관됩니다. 보석·구입 스킨·판 상태는 주소와 기기별로 저장되며 다른 주소로 자동 복사되지 않습니다.
