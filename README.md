# 🍉 수박정원 · 다섯 가지 작은 게임

**[수박정원 플레이](https://sanghyun8420.github.io/my_Ai_app2/)**

제목을 누르면 수박정원·사과모아·블록정원·과일 원정대·사과 키우기를 고를 수 있습니다. 게임마다 돈과 보석, 성장 기록을 따로 저장합니다.

- 수박정원: 과일 합치기, 보호되는 흔들기, 선택 지우개, 다양한 스킨과 모드
- 사과모아: 네모 안 사과 숫자의 합을10으로 만드는 가로 퍼즐
- 블록정원: 블록을 끌어 가로·세로 줄을 채우는 퍼즐
- 과일 원정대: 세 동료의 자동 전투, 동전 강화, 쉬움부터 지옥까지75보스 구간, 21종 도구 뽑기와 장착
- 사과 키우기: 물·영양·햇살, 수확과 정원 강화, 다섯 품종, 자리를 비운 동안의 성장

사과모아는 나가면 새 판으로 시작하며, 수박 특수 모드는 나가거나 재접속하면 기본 수박게임으로 돌아갑니다. 보석·스킨·최고점수는 유지됩니다.

게임별 음악·효과음 설정, 자동 저장, 게스트 플레이와 게임 계정, 수박·사과·블록 친구 대전 및 리더보드를 제공합니다. 원정대와 사과 키우기는 개인 성장 게임입니다.

## 실행과 수정

이 저장소는 실행용 정적 파일입니다. 설치나 빌드 없이 GitHub Pages에서 실행하며, Pages 설정은 main 브랜치의 /(root)를 사용합니다. main 변경 사항이 새 버전으로 배포됩니다.

계정·친구·리더보드·방 기능은 기존 수박정원 Worker/D1 API를 사용합니다. 보석·스킨·판 상태·성장 기록은 주소와 기기별로 저장되며 다른 주소나 기기로 자동 복사되지 않습니다. 뽑기는 게임 안에서 얻는 보석만 사용합니다.
